# Free Stylized Sprite VFX

VFX textures by Jony / Kalponic Studio, downloaded from [itch.io](https://kalponic-studio.itch.io/free-stylized-sprite-vfx). The pack contains 15 stylized VFX flipbooks / sprite sequences.

Each effect folder contains numbered PNG frames named `frame_001.png`, etc., in playback order. Frames were extracted from the supplied archive and renamed with zero padding; screenshot previews and duplicate nested archives were omitted. Image pixel data was not edited.
