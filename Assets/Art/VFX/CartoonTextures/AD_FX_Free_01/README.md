# AD_FX - FREE 01

VFX textures downloaded from [AD_FX on itch.io](https://ad-fx.itch.io/free). The pack provides transparent PNG sprite sheets and image sequences for Unity and other engines.

## Contents

- `Sprite_Sheets/sprite_sheet.png` - 1024 x 1024 sprite sheet.
- `Image_Sequences/frame_01.png` to `frame_09.png` - nine 1024 x 1024 sequence frames.
- `Preview/animation.gif` - animated preview from the original archive.
